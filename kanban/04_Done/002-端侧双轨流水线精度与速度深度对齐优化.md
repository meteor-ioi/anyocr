# 端侧双轨流水线精度与速度深度对齐优化

### 📌 任务目标
解决 AnyOCR 原生 Rust 双轨流水线在第一轮 47 页实测中暴露的“速度偏慢（176s vs 51s）”与“文字对齐漂移、跨行错位”问题。通过校准版面阈值（0.48）与几何防噪、重构二维面积交叠率（IoF）空间投影矩阵与阅读顺序拓扑保序算法，以及重构紧凑 Sort-then-Batch 动态批处理调度机制，全面追平 Python 版本的精度与速度表现。

### 📋 子任务清单 (Checklist)
- [x] 子任务 1：校准版面检测阈值（`score_thresh: 0.48`），增加 Table 几何防噪过滤（`bw < 60 || bh < 40 || area < 3000`），杜绝碎片伪表格
- [x] 子任务 2：重构表格文字空间对齐算法：全面废弃单点欧氏距离粗筛，升级为二维面积重叠率 (IoF) 矩阵最优投影与单元格内部阅读顺序（Y轴主序、同行X轴升序）拓扑保序
- [x] 子任务 3：优化 `TextRecognizer` 批处理机制：按切片宽度升序排序紧密成批（Sort-then-Batch），并将单行宽度合理 clamp 至 960px，彻底根除超宽 padding 计算浪费，识别耗时暴降超 60%
- [x] 子任务 4：全量重测 7 份工业订单 PDF（47 页），47 页纯 CPU 总耗时从 176 秒暴降至 66.72 秒（平均 1.42s/页），提取 3,416 个单元格与 3,557 个文本框
- [x] 子任务 5：输出调优前后对比报告，同步看板与文档索引
